KEY FILES EXPLAINED:
================================================================================

src/App.js (Main Application Logic)
- Uses React hooks (useState, useRef, useEffect)
- Manages chat message state
- Sends messages to backend API at http://localhost:5000/api/chat
- Handles loading and error states
- Auto-scrolls to latest message

src/components/ChatWindow.js (Message Display)
- Maps through messages array
- Colors: User messages (purple gradient), Bot messages (light gray)
- Shows loading spinner while waiting for response
- Displays welcome message when chat is empty

src/components/ChatInput.js (Input & Send)
- Text input field
- Send button that's disabled while loading
- Clears input after sending
- Supports Enter key to send

src/index.css (Styling)
- Gradient background (purple to violet)
- Chat container with rounded corners
- Message bubbles with different colors
- Input field with focus effects
- Loading spinner animation
- Responsive mobile design

backend/server.js (API Server)
- Express.js setup with CORS
- Groq LLM client integration
- POST /api/chat - Main chat endpoint
- GET /api/health - Health check
- POST /api/clear-history - Clear conversation
- Maintains conversation history in memory

================================================================================
HOW IT WORKS:
================================================================================

1. User types message in ChatInput component
2. Form submits to App.js via onSendMessage function
3. App.js adds user message to state and shows it
4. App.js fetches POST http://localhost:5000/api/chat
5. Backend receives message and adds to conversation history
6. Backend sends full history to Groq LLM
7. Groq generates response based on context
8. Backend returns response to frontend
9. App.js adds bot message to state
10. ChatWindow renders all messages
11. Auto-scroll shows latest message

Total roundtrip: ~2-3 seconds (Groq is fast!)

================================================================================
SETUP INSTRUCTIONS:
================================================================================

1. GET GROQ API KEY:
   - Visit https://console.groq.com/keys
   - Sign up/login (free)
   - Copy your API key

2. CONFIGURE BACKEND:
   cd backend
   cat > .env << EOF
   GROQ_API_KEY=your_key_here
   PORT=5000
   EOF

3. INSTALL DEPENDENCIES:
   cd ..
   npm install          # Frontend
   cd backend
   npm install          # Backend
   cd ..

4. START BACKEND (Terminal 1):
   cd backend
   npm start
   # Runs on http://localhost:5000

5. START FRONTEND (Terminal 2):
   npm start
   # Opens http://localhost:3000

6. CHAT:
   Type message and hit Send or Enter key

================================================================================
TROUBLESHOOTING:
================================================================================

BACKEND WON'T START:
- Check port 5000 is free: lsof -i :5000
- Verify GROQ_API_KEY is in backend/.env
- Check backend/node_modules exists: cd backend && npm install

FRONTEND CAN'T CONNECT:
- Ensure backend is running on http://localhost:5000
- Check browser console for errors (F12)
- Try curl http://localhost:5000/api/health

NO RESPONSE FROM AI:
- Verify API key is valid at https://console.groq.com
- Check internet connection
- Wait 2-3 seconds (first response is slower)
- Check backend console for errors

SLOW RESPONSES:
- First response: 2-3 seconds (normal)
- Subsequent: 1-2 seconds
- This is normal Groq behavior
