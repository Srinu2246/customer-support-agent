                    START HERE - AI CHATBOT QUICK SETUP
================================================================================

Your AI Customer Support Chatbot is ready! Follow these 5 steps:

STEP 1: GET GROQ API KEY (2 minutes)
================================================================================
1. Go to: https://console.groq.com/keys
2. Sign up/login (free)
3. Copy your API key

STEP 2: SET UP BACKEND (1 minute)
================================================================================
Open terminal, run:

  cd backend
  
Create .env file with:

  GROQ_API_KEY=paste_your_key_here
  PORT=5000

(or use this command to auto-create it)

STEP 3: INSTALL DEPENDENCIES (2 minutes)
================================================================================
Backend:
  cd backend && npm install
  
Frontend (from root):
  npm install

STEP 4: START BACKEND (Terminal 1)
================================================================================
  cd backend
  npm start
  
Wait for: "Server is running on http://localhost:5000"

STEP 5: START FRONTEND (Terminal 2)
================================================================================
  npm start
  
Your browser opens at http://localhost:3000 - You're done!

================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot reach backend"
SOLUTION: 
  - Check backend is running on port 5000
  - Check backend console for errors

PROBLEM: "Backend crashes at startup"
SOLUTION:
  - Make sure GROQ_API_KEY is in backend/.env
  - Run: cd backend && npm install

PROBLEM: "Port 5000 already in use"
SOLUTION:
  - Edit backend/.env: PORT=5001
  - Update src/App.js fetch URL to 5001

PROBLEM: "Slow responses"
SOLUTION:
  - First response: 2-3 seconds (normal)
  - Subsequent: 1-2 seconds
  - This is normal!

For more help → See README.md
